# Ray Tracer Documentation

This folder is the source of truth for the ray tracer's design, known issues,
and planned work.

- [IMPL_NOTES.md](./IMPL_NOTES.md) — how the current implementation works,
  including intentional backend differences and known incomplete paths.
- [REVIEW.md](./REVIEW.md) — the original audit, with a resolution-status note
  distinguishing fixed, retired, and deferred findings.
- [PLAN.md](./PLAN.md) — completed remediation plus the bounded follow-up plan
  and verification gates.

The documents describe the code as of 2026-08-04. Update them alongside
changes to renderer behavior, sampling PDFs, material semantics, or backend
parity.
