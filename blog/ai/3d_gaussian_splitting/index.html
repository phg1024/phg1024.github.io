[comment]: (Paper Reading Notes (1): 3D Gaussian Splatting for Real-Time Radiance Field Rendering) [comment]: <brief> (Reading notes for the SIGGRAPH 2023 paper: 3D Gaussian Splatting for Real-Time Radiance Field Rendering.)</p> <h1>Paper Reading Notes (1): 3D Gaussian Splatting for Real-Time Radiance Field Rendering</h1> <p><a href="https://repo-sam.inria.fr/fungraph/3d-gaussian-splatting/">Link to paper</a></p> <h2>Main Achievements</h2> <ul> <li>30fps novel view synthesis at 1080p</li> </ul> <h2>Key Elements</h2> <ul> <li>3D Gaussians for scene representation</li> <li>Anisotropic covariance optimization for accurate scene representation</li> <li>Fast, visibility-aware splatting algorithm, using a tile-based and sorting renderer</li> </ul> <h2>Core Algorithm</h2> <h3>Differentiable 3D Gaussian Splatting</h3> <p>3D Guassians are defined as ellipsoids at $ \mathbf x $ with full covariance matrix $ \Sigma $:</p> <p>$$ G(\mathbf x) = e^{-\frac{1}{2}\mathbf x^T \Sigma^-1 \mathbf x} $$ and this can be alternatively represented with an epplisoid with rotation: $$ \Sigma = \mathbf R \mathbf S \mathbf S^T \mathbf R^T $$ so it can be efficiently represented with a 7-element vector (3 for scaling and 4 for quaternion). Each 3D Gaussian also uess sphereical harmonics to represent its color component, which can be written as the SH coefficient vector $ \mathbf c $. To summerize, each 3D Gaussian can be represented with the tuple $ (\mathbf x, \mathbf r, \mathbf q, \mathbf c, \alpha) $ where $ \alpha $ is the opacity and $ \mathbf r $ is the rotation vector.</p> <h3>Adaptive Density Control</h3> <ul> <li>Initial 3D Gaussians are formed with SfM points;</li> <li>Adaptive control focuses on "under reconstruction" (not enough 3D Gaussians for the detailed geometric features) and "over reconstructions" (Gaussians cover too much area?) regions;</li> <li>Densify Gaussians based on view-space gradients: clone in "under-reconstruction" regions and split in over reconstruction regions;</li> </ul> <h3>Fast Differentiable Rasterization</h3> <p>Tile-based rendering and pre-sorting all primitives for the entire image:</p> <ul> <li>Split the screen into 16x16 tiles</li> <li>Cull 3D Gaussians against view frustum and tiles</li> <li>Instantiate Gaussians and assign them to tiles using depth and tile ID as key</li> <li>Sort Gaussians using fast GPU Radix sort</li> <li>For each tile, create a list of Gaussians and rasterize each tile independently</li> <li>Warm up the computation at low resolution then upsample twice</li> <li>Gradual optimization for SH bands: start from zero-th order and then add more bands</li> </ul> <h2>Unsorted Thoughts</h2> <ul> <li>Very efficient choice for scene representation is key to enabling real-time rendering at 1080p; at the same time the representation may not be the most suitable for digital humans.</li> <li>How do we enable it for motion? One recent attempt is <a href="https://dynamic3dgaussians.github.io/">this work</a>.</li> <li>The Guassians placement/generation algorithm is still quite empirical. Could we derive that from image features automatically? Maybe even make it trainable?</li> </ul> <h2>References</h2> <ul> <li><a href="https://light.princeton.edu/publication/point-based-radiance-fields/">Differentiable Point-Based Radiance Fields for Efficient View Synthesis</a></li> <li><a href="https://xharlie.github.io/projects/project_sites/pointnerf/">Point-NeRF: Point-based Neural Radiance Fields</a></li> <li><a href="https://github.com/Angtian/VoGE">VoGE: A Differentiable Volume Renderer using Neural Gaussian Ellipsoids for Analysis-by-Synthesis</a></li> <li><a href="https://cgl.ethz.ch/research/past_projects/surfels/ewavolumesplatting/index.html">EWA volume splatting</a></li> <li><a href="https://openaccess.thecvf.com/content/CVPR2021/papers/Lassner_Pulsar_Efficient_Sphere-Based_Neural_Rendering_CVPR_2021_paper.pdf">Pulsar: Efficient Sphere-based Neural Rendering</a></li> <li><a href="https://repo-sam.inria.fr/fungraph/differentiable-multi-view/">Point-Based Neural Rendering with Per-View Optimization</a></li> <li><a href="https://cseweb.ucsd.edu/~ravir/nerficbs.pdf">NeRFs: The Search for the best 3D Representation</a></li> <li><a href="https://dynamic3dgaussians.github.io/">Dynamic 3D Gaussians: Tracking by Persistent Dynamic View Synthesis</a></li> </ul>
